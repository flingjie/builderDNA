# 深度分析

Step 4 的核心。不要只总结原文，回答一个问题：

> **如果我是 Agent Solution Expert，我应该从这条推文中学到什么？**

## 低质量 vs 高质量分析

原推文：

> We reduced agent latency by 40% by changing the tool execution architecture.

低质量（只是复述）：

> 作者通过优化 Tool Execution 降低了 Agent 延迟。

高质量（提炼可迁移认知）：

> 真正值得学的不是「降了 40% 延迟」，而是它说明 **Agent 性能优化不能只看 LLM latency**。
>
> Agent 端到端 latency 可拆成：
> `LLM → Tool Selection → Tool Execution → Observation → Context Update → Next LLM`
>
> 如果 Tool Execution 占 Loop 大头，继续换更快的模型几乎没收益。启发是：**先做 Trace，再优化模型**——先定位 Agent Loop 里真正的 latency bottleneck。

## 七个分析角度

「值得学习的点」不是凭感觉写，而是从下面七个固定角度提炼出来。前 3 角是「理解这条推文在做什么」，后 4 角是「评估它做得好不好」，最后综合成 1～3 条可迁移认知。

**理解（前 3 角）：**

1. **要解决什么问题** — 它回应 / 解决的真实问题（不是标题复述）。问题越真实越具体，越值得看。
2. **读者是谁** — 它写给谁：Agent 工程师 / FDE / 创业者 / 研究者 / 决策者。推断依据：作者 bio/职位、术语密度（工程细节 vs 决策语言）、示例场景（内部工程 vs 客户交付）。读者错了，这条对「我」的价值要打折。
3. **读完应该做什么 / 明白什么** — 一个读者读完能带走的唯一结论或行动。说不出一条 takeaway 的，通常不值得进 Top 10。

**评估（后 4 角，质量四维）：**

4. **清晰度** — 核心主张能否一句话复述，还是绕圈子。
5. **具体性** — 有没有数据 / 代码 / 步骤 / 具体场景，还是抽象口号。
6. **可信度** — 证据强度层级：一手生产经验 > benchmark / 实验 > 技术分析 > 观点 > 新闻（同 scoring-rubric 的 Rule 3）。
7. **可执行性** — 读完能不能立刻落地成一个实验 / 改设计 / 改代码。

质量四维是**每条的诊断注**，不是排名分——排名分仍是 scoring-rubric 的 Learning Score。四维与 Learning Score 的对应：可信度 ≈ Evidence、可执行性 ≈ Practicality、具体性 ≈ Evidence + Originality 的重叠。

## Top 10 条目格式

```markdown
## #N 标题

作者：
链接：

### 要解决什么问题
（这条推文回应 / 解决的真实问题，不是标题复述）

### 读者是谁
（它写给谁：Agent 工程师 / FDE / 创业者 / 研究者 / 决策者；为什么是这群人）

### 读完应该做什么 / 明白什么
（一个读者读完能带走的唯一结论或行动）

### 质量评估
- 清晰度：⭐⭐…（一句话理由：核心主张是否一句话能懂）
- 具体性：⭐⭐…（一句话理由：有没有数据 / 代码 / 步骤 / 具体场景）
- 可信度：⭐⭐…（一句话理由：证据强度）
- 可执行性：⭐⭐…（一句话理由：能不能落地成实验 / 改设计 / 改代码）

### 值得学习的点
（综合上面七角，提炼 1～3 条可迁移认知——不是复述，是「我能带走什么」）

### 对 Agent Engineering 的启发
（这个观点如何迁移到 Agent 系统）

### 可以进一步验证
（一个可以自己实践的实验）

### 我的判断
> 值得深入 / 值得实践 / 值得观察 / 有启发但不确定
```

## 「我的判断」评级

- **值得深入** — 改变认知，值得深挖作者其他内容
- **值得实践** — 可直接落地成自己的实验
- **值得观察** — 有信号但证据不足，持续跟踪
- **有启发但不确定** — 观点有趣，暂不能判断对错

## 5 个必问问题

这 5 问是进 Top 10 之前的**预筛硬门槛**，与上面的七角分析是两层：先过 5 问筛资格，再过七角做深度分析。

每条候选进 Top 10 前先过一遍（第 5 问是硬门槛）：

1. 这条内容为什么值得我看？
2. 作者真正解决了什么问题？
3. 这里有没有我以前不知道的东西？
4. 这个经验能不能迁移到 Agent Solution？
5. 我能不能基于它形成一个自己的观点？
