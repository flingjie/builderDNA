# Superpowers Plans & Specs — historical

These `plans/` and `specs/` files are **historical planning documents** from the
superpowers workflow. They are **superseded** by the current implementation in the
repo — the live contract is `docs/product-contract.md`, `schema.md`,
`models/payload.py`, and `cli/main.py`.

Do not treat any plan/spec here as current truth. They were captured at the time
the work was planned and have not been kept in sync with later refactors (notably
the Technology Intelligence focus refactor, which removed `twitter-discussion`
and `reddit-outreach`).
